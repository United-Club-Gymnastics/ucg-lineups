# UCG Lineups

Stopgap tool for UCG Nationals: clubs set competing order, UCG builds squads, and the app prints
scorecards and rotation sheets.

- Working agreements and layout: [CLAUDE.md](CLAUDE.md)
- Behaviour and decisions: [docs/spec.md](docs/spec.md)
- Build notes: [docs/notes.md](docs/notes.md); copied code: [docs/provenance.md](docs/provenance.md)
- Commands: `npm run dev`, `npm run build`, `npm run lint`, `npm test`
